Tech 1aQuantization algorithms: scale search to distillation QAT

2 → 0.5pt accuracy drop · 2023 – 2026

Context
Production models run in INT8 / INT16 on automotive chips, and releases tolerate very little accuracy loss.
Challenge
PTQ lost about 2 points on these models and needed hand tuning; task-loss-only QAT can shift the model's operating point.
Action
  • Scale-search PTQ (2023; patent granted in 2026): layer-wise parameter search against similarity to the float outputs.
  • AutoQuant (2024): automated quantization training with learned step sizes, for complex CNN + transformer hybrids.
  • Distillation QAT (since 2025): float teacher, PTQ-initialized student; scaled up in 2026 for end-to-end trajectory outputs.
Result
Accuracy drop from quantization on five production perception models fell from about 2 points to about 0.5; in a 2023 traffic-light experiment mAP went from 0.747 back to 0.803 (float 0.800).

Tech 1bQuantization toolchain: one flow for four chip families

3–5 daysper-model adaptation · 2022 – 2026

Context
Models have to run on Horizon, NVIDIA, Qualcomm and AXERA chips, each with its own toolchain and semantics.
Challenge
Chip-by-chip adaptation: over two weeks to adapt a new model, 30–60 minutes for one TensorRT build.
Action
  • Three layers: generic quantization, AI auto-adaptation (parameter search, configs) and per-chip platform adapters.
  • QNN Web, one-click multi-chip conversion: graph-derived configs, a TensorRT build cache, job queue, MCP endpoints for AI agents.
Result
Per-model adaptation went from about two weeks to 3–5 days. 4,273 production conversions so far, with a TensorRT build down to under 5 minutes.

Tech 2b · 2aDeployment framework: parity checks and inference runtime

≤ 2 LSBworst-case LUT error · 2022 – 2026

Context
A dozen transformations lie between quantization training and the vehicle, and each can change the numbers.
Challenge
“The board differs from float” is hard to localize, and x86 simulation replay must stand in for the board.
Action
  • Parity checking: adjacent stages compared on identical inputs (12 checkpoints) to find where a deviation first appears.
  • Adaptive lookup tables: error measured on the actual output of the fixed-point implementation; export is blocked if the bound is missed.
  • On-vehicle inference runtime: added a TensorRT custom operator and int32 inputs to the unified multi-backend runtime; landed a new chip's backend adaptation for 20+ models.
Result
On 600 LUT modules from four production graphs the worst-case error is at most 2 LSB, with 85% fewer tables than a uniform 126-table scheme. A regression set of past failures caught issues before release on three production programs.

Tech 3bProduction releases: ≈19 models, two-week cadence

≈19production models · 2022 – 2026

Context
About 19 production driving and parking models in 8 architecture families; several programs in parallel; a release every two weeks.
Challenge
Each family quantizes differently. One prediction-planning model was blocked by abnormal trajectories.
Action
  • Process: quantization designed alongside float training; handover template; past issues re-tested before each release.
  • Hard cases: error analysis showed error compounding through deep layers; switched to two-stage quantization with full QAT, INT16 at sensitive points.
Result
For one BEV detection model, quantization effort per release fell from about one person-week to about two person-days. The prediction-planning model's trajectory anomalies were eliminated and the fix merged to mainline.

Tech 3a · 3cEnd-to-end models: training, quantization, road tests

11candidates × 25 metrics · 2025 – 2026

Context
Models are moving to end-to-end; a trajectory-output planner accumulates quantization error over depth and time.
Challenge
Connect training, quantization and deployment; bring the quantized model up to on-vehicle testing.
Action
  • Training: PyTorch 2.x migration; lead the design in which five perception tasks share the end-to-end image encoder (in progress).
  • Quantization: large-scale distillation from the float model; eleven candidates, one variable each, the same 25 metrics.
  • Vehicle validation: parity checks, then the board, then iteration with road tests.
Result
The quantized end-to-end planner went to on-vehicle testing. In the measured occupancy setup, training time per iteration went from 1.56 s to 0.71 s (−54%).
