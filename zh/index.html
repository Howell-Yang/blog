与浮点模型逐 case 一致的量化：四代算法演进

  • 问题：量产对回退近乎零容忍，AEB 目标晚一帧检出即失败；而只用任务损失的 QAT 会改变 precision/recall 工作点，交付的实际上是一个“重训模型”。
  • Scale-search PTQ（2023，已申请专利）：以与浮点输出的 cosine 相似度为目标，分级搜索量化参数：校准方式 × 参数组合 → 逐层前/后向搜索 → 逐层量化。红绿灯检测模型上，默认校准的 mAP 为 0.747，逐层量化恢复到 0.803（浮点 0.800）。
  • LSQ AutoQuant（2024）：面向 CNN + Transformer 混合结构（矢量地图、时序跟踪），学习量化步长，用 AdaRound 式取整约束权重漂移，并以浮点中间特征监督；训练前做跨层均衡（CLE）与 LayerNorm–Linear 融合。
  • 蒸馏 QAT → 大规模 QAD（2025–2026）：浮点模型做教师、PTQ 模型为起点，任务损失 + 特征/输出蒸馏。在端到端规划模型上以单变量对照实验（25 项关键指标、388 个公共标量）确认：场景边界重置时序状态、教师独立历史、训练后期权重锚定是必要条件。
  • 结果：5 个量产感知模型量化掉点由约 2 个点降至约 0.5 个点；端到端规划模型的量化版本进入实车测试；模型 owner 已开始自助完成 auto-QAT 发版。

预测规划模型的量化误差累积攻坚（QuestNet v3）

  • 问题：模型量化后轨迹输出异常，PTQ 与常规 QAT 均失效，量产交付受阻。
  • 用逐层误差与累积误差分析定位出误差在深层网络逐级累积的机制，对敏感层与鲁棒层做差异化处理；用实验否定“冻结部分层再微调”的折中方案，改为两段式量化 + 全量 QAT。
  • 基于对芯片算子特性的理解，推动全链路 INT16 量化，为误差累积留出数值余量。
  • 结果：轨迹异常消除，方案合入主线并完成发版验证；“中融合模型量化必须全量训练”成为团队方法论。

定点数值一致性：自适应查表与分层对齐

  • 自适应查表：rsqrt、reciprocal、exp、sigmoid 等非线性算子在 NPU 上以定点分段查表实现。算法以芯片真实定点输出码（而非浮点近似）度量误差，保留原始 6 表边界，对误差最大的段递归二分，预算用尽仍超限则阻断导出。4 个量产计算图共 600 个查表模块：平均 0.217 LSB、最大 2 LSB（均匀 126 表方案最大 11,381 LSB），表数量减少 85%。
  • 分层对齐：Float → QAT → 内部 IR → LibTorch → HBIR → HBM → 板端后处理，每个阶段只与前一阶段在相同输入下比对，让每个不一致只可能来自一处；定位了归一化层 rsqrt 查表分段点、upsample align_corners 不一致、位姿精度等问题。
  • 发版门禁：结论按证据分级（源码 / 编译 / 仿真 / 板端 / 实车），新特性默认关闭（feature flag），历史量化问题回归集每次发版前重跑；在 3 个车企项目中把量化问题拦截在发版之前。

工具链与平台：从一键转换到平台化量化部署

  • QNN Web 一键多芯片模型转换服务（gRPC 前后端分离、按 ONNX 计算图自动生成配置、TensorRT timing cache；后续加入任务数据库、队列和面向 AI Agent 的 MCP 接口）：累计 4,273 次量产转换，单次编译 30–60 分钟 → 约 5 分钟，人工耗时减少约 80%。
  • 把多平台量化拆为通用量化层 / AI 自动适配层 / 平台适配层：单模型量化适配周期由约 2 周缩短到 3–5 天。带领团队打通高通（模型拆分与耗时优化，推理耗时降低 50% 以上）、TensorRT QDQ INT8 和地平线 J6P 上的 VLM 量化链路。
  • 2026.11 起牵头平台化量化部署框架的目标架构（设计稿，路线图至 2027 Q2）：以定点仿真结果为唯一真值，用七份带版本的契约（产物身份、IR 元信息、IO 契约、真实 IO 包、精度方案、平台能力、门限）连接训练、转换、车端三个代码库，逐跳门禁默认阻断，并以“敏感度 × 板端时延代价”的闭环自动规划混合精度。

耗时建模、模型架构与训练效率

  • 结构级耗时模型：按模块结构预测板端耗时，Occupancy 模型预测 19.38 ms、实测 19.25 ms（误差 0.7%）；在写代码之前就否定了“扩大范围 + 10 Hz”直接上线的方案，并验证 MapFormer query 合并可节省 2.1–3.3 ms。
  • OneModel 二期（进行中）：5 个感知任务、9 路相机共享图像 backbone 与 neck，按帧率折算预计每帧节省 5–9 ms；对 5 个任务 checkpoint 的特征做 PCA 冗余分析确定 backbone 结构，并以通道对齐 + 闭式线性求解合成预训练权重；采用 ReLU6 + 代理梯度的量化友好激活，修复 backbone 感受野中心偏移。
  • BEV Occupancy 训练迁移到 PyTorch 2.x：单 iter 1.56 s → 0.71 s（−54%，V100、batch 16、AMP），显存降低 9%，完成 1–112 卡扩展性压测。
  • 端到端驾驶模型架构设计（提案阶段，尚未训练）：camera-first 的 token 化方案，9 路相机经共享编码器 token 化，流式 Transformer + 位姿感知记忆，以曲率/加速度节点表示的多模态规划头，并从设计之初给出蒸馏 + INT8 量化的落地路径。
